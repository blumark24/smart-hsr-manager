## 4. P0 — ما الذي يوقف GO حتى لو ارتفع مجموع النقاط؟

1. **إثبات الفصل المادي والمنطقي** بين بيئة اختبار تجريبية وFirebase/Firestore/Storage الفعليين للبلدية، دون كشف أسرار أو نسخ سجلات أو هوية.
2. **تثبيت SHA واحد** بعد مراجعة التعديلات المختارة، وPreview معزول مطابق له وCI متطابق.
3. **اختبارات مصادقة وصلاحيات وظيفية** بحسابات مصرح بها تجريبية: u1–u8، المدير، User Center، Single-Use Lands SSO، عزل تبويبات/بلديات وتغير الدور.
4. **قبول ملفات الأراضي**: الأمر والقرار والمستفيد والمخطط والقطعة والمستندات، التحقق من تخزين bytes الحقيقي في البيئة التجريبية، سجل التدقيق، عدم اعتماد تلقائي.
5. **قبول الحصر/الحركة/AI** مع أدلة اصطناعية وحالات فشل منضبطة وإشراف بشري؛ Desktop / iPad / Mobile؛ وقياسات زمن استجابة.
6. **مراجعة ومتطلبات قانونية/تنظيمية مطبقة**: صلاحيات الجهة، معالجة البيانات، العقود، الإقامة السحابية، مسؤول AI ونطاق التحكمات NCA.
7. **تفويض النشر البلدي** من صاحب الصلاحية وتأكيد Backup/Restore/Rollback دون المساس بالبيانات الحقيقية خلال التحقق التحضيري.

## 5. تحديث التقييم القادم (دون تغيير الأوزان)

| الحقل | طريقة التوثيق |
|---|---|
| Criterion ID | A..H + رقم البند الجزئي مع سقف النقاط |
| SHA / branch | SHA الفعلي لا اسم الفرع فقط |
| Environment | synthetic-local / isolated-preview / production-read-only |
| Evidence | Run URL + artifact/hash + تاريخ + المسؤول |
| Status | PASS / PARTIAL / BLOCKED / FAIL / NOT EVALUATED |
| Points | المكتسبة من الوزن المحدد بعد مراجعة مستقلة |
| Regulatory note | التفسير الداخلي لا يُقدَّم بصفة شهادة سدايا أو NCA |

**لن ترتفع الدرجة تلقائيًا بسبب إنشاء المستندات.** أول تغيير رقمي مشروط بأن يراجع صاحب الاختصاص الأدلة والقبول.

### الحدود الحساسة

**لا تعديل لـProduction، ولا أسماء مستخدمين حقيقيين، ولا منح أو مستفيدين أو وثائق أو رموز تحقق، ولا تنزيل بيانات Firebase أو Storage.** كل التحقق المستقبلي للوظائف الحية يجب أن يستخدم Staging مفصولًا وبيانات اصطناعية، وبإذن مسؤول أمن ومالك البيانات.
