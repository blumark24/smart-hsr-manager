# SMART HSR | منصة الحصر والتشغيل البلدي الذكي

> **حالة هذا المستند:** توثيق فني لمستودع SMART HSR. لا يُعد اعتمادًا حكوميًا أو شهادة من سدايا/الهيئة الوطنية للأمن السيبراني، ولا يثبت أن جميع وظائف النسخة المنشورة اجتازت اختبار قبول حيًا.
>
> **سياسة حماية البيانات:** الدومين البلدي الفعلي وبيانات المنح والمستفيدين والموظفين والمستندات **ممنوع تعديلها أو نسخها إلى بيئات الاختبار** دون تفويض موثق من مالك البيانات. أي اختبار جديد يجب أن يستخدم هوية وبيانات اصطناعية معزولة.

## ما المشروع؟

SMART HSR منتج متعدد الوحدات لدعم أعمال البلدية: لوحة المدير ومركز المستخدمين، الحصر الميداني، الخريطة التشغيلية، التوأم الرقمي، الحصر الذكي لمنح الأراضي والممتلكات، الحركة الذكية والتقارير. الفصل بين الأدوار والبلديات وحقوق الاطلاع شرط أساسي لاختبار القبول.

## البنية التقنية الفعلية

- **Frontend:** صفحات HTML وCSS وJavaScript، تدعم العربية واتجاه RTL، مع وحدات عميل ومسارات مستقلة. يَظهر في المستودع `manager.html` و`login.html` و`manager-login.html` و`lands/index.html`.
- **Hosting / API:** مشروع **Vercel** للواجهة وواجهات Serverless ضمن `api/`، مع إعداد المسارات وترويسات الأمان في `vercel.json`.
- **Authentication / Authorization:** Firebase Authentication، طبقة صلاحيات API في `api/_lib/authz.js`، وقواعد Firestore في `firestore.rules`؛ **التطابق بين القواعد المنشورة والشفرة لا يُفترض دون تحقق**.
- **Storage:** يوجد تكاملات تخزين ومستندات في المصدر؛ **وجود كود للتخزين أو سجل metadata لا يثبت نجاح رفع bytes إلى مخزن فعلي**.
- **AI:** ميزات متعددة بمستويات جاهزية مختلفة. **مساعد الأراضي الذي عولج في PR #107 يستخدم إجابات حتمية قائمة على القواعد؛ لا تعامله كنموذج لغوي خارجي**. مسار تحليل الصور الميداني يحتاج اعتماد تشغيل وخصوصية واختبار مستقل.
- **Runtime:** `package.json` يحدد **Node.js 22.x**. تعتمد اختبارات معينة على Firebase Emulator/Playwright محليين، وليس على بيانات البلدية الفعلية.

## تشغيل اختبارات آمنة ومحلية

تستلزم الاختبارات تثبيت الاعتماديات في بيئة تطوير معزولة وخالية من مفاتيح Production. من جذر المستودع:

```bash
npm ci
node --test test/lands-assistant-honest-attention.test.cjs
node --test test/lands-executive-header-profile-ai.test.cjs
```

> **ملاحظة دقيقة:** `npm test` في ملف `package.json` الحالي مجرد Placeholder يُنهي التنفيذ بالخطأ؛ لا تستخدمه دليلًا على نجاح أو فشل جميع الاختبارات. ولم تُجر هنا عملية تشغيل محلي جديدة بهذا الدليل.

أوامر موجودة في `package.json`: `npm run build:css`، و`npm run test:lands-ui`، و`npm run test:lands`، و`npm run test:rules`. يتطلب الأخير أدوات Firebase Emulator؛ ويجب تشغيله على مشروع اصطناعي منفصل فقط.
